Case study · MSIG USA

MSSQL Agent Suite

Context

Who needed SQL Server data, how they got it before, and what that cost.

Constraints

  • Regulated insurance data: no credentials stored anywhere in the system.
  • Every request authenticated through Entra MFA.
  • Other constraint: latency, audit, scope

What I built

Twelve single-purpose skills, each doing one database task well, with two orchestrators routing requests to the right skill. Narrow skills made each one testable and reviewable on its own.

Decisions

  • Why many narrow skills instead of one general agent
  • Why two orchestrators and how work splits between them

Results

  • X% fewer ad-hoc requests
  • N analysts onboarded
  • time-to-answer from X to Y
